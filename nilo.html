Nilo
Gestionnaire de projet local — entièrement hors ligne.

À propos

Nilo est une application desktop de gestion de projets inspirée du modèle vault d'Obsidian : les données restent sur le disque, dans le dossier de ton choix. Pas de compte, pas de cloud, pas de serveur.

Tu choisis un dossier → Nilo y crée une base SQLite locale → tu travailles. C'est tout.

Fonctionnalités

Vue Kanban
Glisser-déposer entre les colonnes À faire / En cours / Terminé
Vue Liste
Toutes les tâches groupées par statut, ajout rapide inline
Dashboard
Vue d'ensemble avec progression par projet
Tâches riches
Titre, description, priorité, assigné, date limite, sous-tâches
Multi-vault
Un vault par client, équipe, clé USB ou NAS — entièrement hors ligne
