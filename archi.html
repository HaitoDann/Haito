ARCHI
Plateforme de gestion d'équipe esport pour PlaZma.

À propos

Plateforme web de gestion d'équipe esport, conçue pour PlaZma. Planning hebdomadaire, suivi des scrims, coaching personnalisé par joueur, satisfaction d'équipe et analytics de performance.

Construit en vanilla HTML/CSS/JS avec Firebase pour la persistance des données. Déployé sur GitHub Pages.

Modules

📅PlanningProgramme d'entraînement hebdomadaire
⚔️ScrimCompte-rendu de matchs entraînement
🔭ScoutingAnalyse des équipes adverses
📋DraftFiches de draft et stratégies
📚EncyclopédieWiki interne ARCHI
💬SatisfactionSuivi du bien-être de l'équipe
📊DashboardAnalytics et indicateurs de performance
👥ÉquipeRoster, staff et profils joueurs

Stack

HTML · CSS · JS Firebase Firestore GitHub Pages Discord Webhooks Riot API
